# User Personas

## Denise (Mobile / High Stress / Low Income)
- Uses an Android phone on a prepaid data plan.
- Works multiple shifts and applies late at night.
- Needs clear plain language, touch-friendly inputs, upfront prep guidance, and fail-safe auto-save persistence.

## Raymond (Blind / NVDA Screen Reader / Keyboard Only)
- Navigates entirely using Tab, Shift+Tab, Space, and Enter.
- Requires explicit `<label for="...">` associations, radio group `<fieldset>` legends, high-contrast 3px focus outlines, and programmatic focus shifting to `#error-summary` on error.
